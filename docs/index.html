INSPECTION SURFACE

One artifact.
Every useful angle.

01

Structure

Navigate applications, frameworks, executables, resources, archives, packages, and disk images as one logical tree.

02

Binary internals

Read headers, slices, sections, segments, relocations, imports, exports, symbols, dependencies, and metadata.

03

Content

Search artifact-wide strings and bytes, inspect mapped addresses, and move through 4 KiB hex windows on demand.

04

Trust signals

Inspect signatures, entitlements, hashes, entropy, dependency resolution, and bounded findings without executing the target.

DESIGNED FOR UNTRUSTED INPUT

Static by default.
Bounded by design.

ByteTrawl does not execute imported programs, mount disk images, or extract archives. Explicit limits cover parser input, recursion, file count, strings, tables, command output, and time.

  • ✓ No symlink traversal during discovery
  • ✓ Lazy hashing, entropy, strings, and dependency work
  • ✓ Cancellable background analysis
  • ✓ External tools launch only when requested

GET BYTE TRAWL 1.0.0

Two tools.
One tap.

Install the native workbench, the automation-friendly JSON CLI, or both. Built for Apple silicon Macs running macOS 13 or later.

Terminal
$ brew tap everettjf/tap
$ brew install --cask bytetrawl
$ brew install bytetrawl-cli

Note: 1.0.0 is ad-hoc signed and not Apple-notarized. macOS may request confirmation on first launch.
