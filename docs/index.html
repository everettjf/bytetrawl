DETAILED SUPPORT

From package identity
to the last useful byte.

Audit means platform-aware release semantics and findings. Inspect means bounded structural parsing and navigation. Identify means reliable recognition with universal search, strings, hashes, entropy, and Hex still available.

01

ArtifactLevelImplemented capabilities

Bounded table of contents, member sizes, checksums, embedded signature count and unsafe paths without launching Installer or extracting payloads.

02

Binaries, containers & data

Mach-O / Universal

Per-slice architecture and ranges, headers, sections, segments, relocations, imports, exports, symbols, dylibs, entry point and signature blob.

PE / COFF

Windows executables and libraries: headers, architecture, sections, relocations, imports, exports, symbols, dependencies, entry point and Authenticode metadata.

ELF

Class, endian, architecture, interpreter, sections, segments, relocations, dynamic symbols, dependencies, entry point and build metadata.

ZIP / tar / ar

Bounded virtual member tables, sizes, modes, links, CRC data and traversal, symlink, absolute-path, expansion-ratio and expanded-size hazards.

DMG / ISO

Structure-based recognition, partitions, volume and sector metadata, compressed blocks and ratios. Images are never mounted.

Structured data

JSON, XML, binary/XML plist, SQLite headers, image dimensions, UTF-8 text and desktop-entry metadata with explicit parser limits.

Unknown files

Magic detection where possible, metadata, artifact-wide search, bounded Hex, strings, SHA-256/SHA-1/MD5 and entropy.

Identify-only

7z, RAR and standalone compressed streams are recognized, but do not yet receive full member browsing or platform-semantic audits.

Deliberate boundary

ByteTrawl is static and read-only. It does not execute imported software, mount images, install packages, automatically extract archives, decompile, debug, patch bytes, or present heuristic findings as malware verdicts. The distributed desktop app currently targets Apple-silicon macOS 13+.

DESIGNED FOR UNTRUSTED INPUT

Static by default.
Bounded by design.

ByteTrawl does not execute imported programs, mount disk images, or extract archives. Explicit limits cover parser input, recursion, file count, strings, tables, command output, and time.

  • ✓ No symlink traversal during discovery
  • ✓ Lazy hashing, entropy, strings, and dependency work
  • ✓ Cancellable background analysis
  • ✓ External tools launch only when requested
